# Sengoku BASARA 4 Sumeragi — PlayStation 3 English Translation

An English translation and editing project for **Sengoku BASARA 4 Sumeragi** on **PlayStation 3**.

> **Current status: English script translated and integrated; editing and Beta preparation ongoing.**

## About the Project

This project aims to make Sengoku BASARA 4 Sumeragi accessible to English-speaking players through an English fan translation.

The English script has been translated and inserted into the game. Editing, graphical corrections and preparation for Beta testing continue; no public Beta or release date is announced.

## Current Work

The project involves translating and editing the game's content while adapting the English text to the original PlayStation 3 presentation.

The work includes:

- English translation of game content.
- Text editing and consistency checks.
- Adaptation of text to the game's interface and display constraints.
- Review of character and menu presentation.
- Further in-game checks as translated sections progress.

Previously discussed work has included character and menu presentation, including character selection and gallery-related screens. The project continues to move through translation and editing work.

## Current Progress

- **Platform:** PlayStation 3
